# TU-Wien-KBS Tap

## How do I install these formulae?

`brew install tu-wien-kbs/tap/<formula>`

Or `brew tap tu-wien-kbs/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tu-wien-kbs/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
